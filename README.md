# 탈출 오피스

## 웹 공개판

- 플레이 주소: https://p4hb.github.io/escapeoffice/
- PC 브라우저와 키보드로 플레이합니다. 방향키로 이동하며 자동으로 공격합니다.
- 로그인 없이 시작하는 게스트판입니다. 클리어 시간 상위 10개는 현재 브라우저에만 저장됩니다.
- 김대리는 서버 없이 동작하는 기본 대화를 사용합니다. `가볼게요` 또는 **보스 만나기**로 보스전에 진입합니다.
- 온라인 계정·전체 랭킹·AI 대화는 공개 게스트판에 포함되지 않습니다.

### 실행 및 배포

Node.js 22.12 이상에서 `frontend` 폴더의 `npm ci`, `npm run dev`로 실행합니다.
`npm test`로 게스트 기록과 대화 로직을 검증하고, `npm run build`로 `frontend/dist`를 생성합니다.

GitHub Pages의 배포 소스는 **GitHub Actions**입니다. `main`의 프론트엔드 변경을 푸시하면
`.github/workflows/deploy-pages.yml`이 테스트·빌드·배포합니다. Pages 설정의 하위 경로를
빌드에 반영하므로 게임 이미지도 `/escapeoffice/`에서 불러옵니다.

로컬에서 배포 경로를 재현하려면 `VITE_BASE_PATH=/escapeoffice/ npm run build` 후
`VITE_BASE_PATH=/escapeoffice/ npm run preview`를 실행합니다. 기본 게스트 모드는 서버나 API 키가 필요하지 않습니다.
기존 계정 UI는 `VITE_GUEST_MODE=false`로 빌드할 때만 활성화됩니다. 이 경우 계정 API와
`/api/chat`을 같은 도메인에서 별도로 서비스해야 하며, 기존 백엔드는 이번 Pages 배포에 포함되지 않습니다.

## 게임소개

### 로그라이크 게임

- 탕탕특공대, 뱀파이어 서바이벌 같은 로그라이크 서바이벌 게임

## 게임 요소

### 플레이어

- 게임 하는 주체
- 방향키를 이용해 이동 가능
- 몬스터와 충돌시 주황색으로 변하고 퇴근시간 10분 추가

### 몬스터

- 퇴근을 방해하는 몬스터
- 부장, 과장, 파일, 보고서 (4종류)
- 몬스터 처치시 랜덤한 무기와 경험치를 일정확률로 드랍

### 무기

- 플레이어가 사용하는 무기
- 최대 3개까지 이용 가능
- 무기를 이용해 몬스터 처치
- 플레이어 레벨업시 무기를 선택해 레벨업 가능
- 7레벨에 도달시 완전강화 무기로 진화! (커피를 max upgrade 시 핫식스로 진화)

### 사용 아이템

- 맵에서 휴가신청서 획득시 스페이스바를 눌러 사용 가능.
- 사용시 반경내부에 있는 몬스터 모두 정지 (휴가를 써서 놀람)

### 플레이어 레벨

- 몬스터를 처치하면 나오는 xp를 획득하여 레벨업
- 레벨업시 보유중인 무기 3개중 하나를 업그레이드 할 수 있음
- 레벨이 올라갈수록 다음 레벨업을 위한 xp 증가

## 게임시스템

### 게임클리어 및 종료 조건

- 5분 안에 보스를 처치 해야함 (남은 시간)
- 보스는 플레이어 레벨이 15레벨이 될 시 등장
- 몬스터 에게 맞으면 퇴근 시간 10분 증가
- 퇴근 시간이 20시 00분이 되면 야근 확정 (게임 오버)

## 세부 기능

### 레벨업 시 무기 업그레이드

- 몬스터를 처치한 xp를 얻어 레벨업시 무기 업그레이드 창 등장
- 위아래 키 및 마우스 클릭을 이용해 업그레이드 할 무기 선택

### 무기교체

- 가지고 있는 3개의 무기 외에 다른 무기 획득시 기존 무기와 교체 가능

## 보스

### 보스 등장 조건

- 플레이어 레벨 15 달성시 거래처 사장 등장(보스)
- 보스 등장 전 거래처 김대리와 대화 (AI)
- 대화에 따라 김대리의 기분 점수 상승 또는 하락
    - 김대리의 기분에 따라 보스의 스탯이 달라짐
- 총 10번의 대화까지 가능하고, 대화를 일찍 끝내고 싶을시 “가볼게요” 입력

### 보스

### 컨셉

- 거래처 사장
- 매우 큰 체력
- 플레이어와 접촉시 퇴근시간 지연

### 공격

- 플레이어에게 이메일 발사
- 이동속도는 느리지만 주기적으로 플레이어에게 돌진

## 기타기능

### 로그인

- 로그인 및 회원 가입 가능
- 로그인시 자신의 플레이 기록 저장

### 무기백과

- 무기 리스트 및 목록 확인 가능
- 데미지, 특징 등 확인 가능. 최종 진화 형태 확인 가능

### 게임 규칙

- 게임에 대한 컨셉과 규칙 확인 가능

## 히든 아이템… (비밀이에요)

### 김대리 보고서

- 맵에 아주 낮은 확률로 김대리에 관한 보고서가 생성 (랜덤위치)
- 보고서에는 김대리가 좋아하는 회의시간과 거래처와의 거래 내역이 명시
- 이 보고서는 매 판마다 랜덤 생성 (AI)
- 이 내용을 김대리에게 정확하게 말해주면 기분이 수직상승 (보스가 약해짐)

## 기술 스택

### 게임엔진 및 프론트 엔드

| 항목 | 설명 |
| --- | --- |
| **Phaser 3** | HTML5 기반 2D 게임 엔진 (주 엔진) |
| **JavaScript (ES6)** | 게임 로직, UI, 씬 관리 전반 |
| **HTML/CSS** | DOM UI 요소 (채팅창, 로그인창 등) |
| **Vite** | 프론트엔드 빌드 도구 (빠른 개발환경) |
| **DOM 연동 Phaser** | Phaser 내에서 HTML 요소 (채팅, 버튼 등) 동적으로 삽입 |
| **Canvas & WebGL** | Phaser 내부적으로 사용됨 (그래픽 렌더링) |

### AI 및 LLM 연동

| 항목 | 설명 |
| --- | --- |
| **Groq 기반 Prompt 엔진** | 김대리 캐릭터의 성격/반응 정의 (게임 내 행동 피드백) 및 대답 생성 |
| **Flask API** | LLM 호출 및 응답 전달용 서버 |
| **LLM 대화 로그 관리** | 유저 대화 히스토리와 상태 추적용 로직 구현 |

### 백엔드 및 서버

| 항목 | 설명 |
| --- | --- |
