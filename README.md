# 탈출 오피스

Phaser 3로 만든 PC 브라우저 생존 게임입니다. 5분 안에 성장하고 거래처 사장을 처치하면 퇴근합니다.

## 플레이와 실행

- 공개 게스트판: https://p4hb.github.io/escapeoffice/
- Node.js 22.12 이상. `frontend`에서 `npm ci`, `npm run dev`.
- 방향키 이동 · 자동 공격 · Space/Q/E 아이템 · ESC 일시정지.
- 강화·교체는 클릭 또는 ↑↓/Enter로 선택합니다.
- 게스트판은 서버 없이 실행하며 대화는 정해진 규칙으로 응답합니다.
- 기록 TOP 10은 현재 브라우저에만 저장됩니다. 규칙 버전 2의 기록은 시연판 기록과 분리됩니다. 예전 기록은 삭제하지 않습니다.

## 규칙 버전 2

제한 시간은 전투 시간 300초입니다. 무기 선택, 대화, ESC 일시정지, 창 전환 중에는 시간·공격·상태 효과가 멈춥니다.
플레이어 레벨 15에서 김대리와 최대 10번 대화한 뒤 보스를 만납니다.
“가볼게요” 또는 **보스 만나기**로 바로 진행할 수 있습니다.

퇴근 시간은 19:00부터 시작하며, 적에게 맞아서 20:00이 되면 실패합니다.
피격 후 1.5초 동안 무적입니다. 대각선 이동도 직선 이동과 같은 속도입니다.

| 적 | 체력 | 접촉 시 추가 시간 | 경험치 |
| --- | ---: | ---: | ---: |
| 파일 | 12 | 6분 | 12 |
| 보고서 | 18 | 6분 | 16 |
| 과장 | 65 | 9분 | 32 |
| 부장 | 150 | 12분 | 60 |

- 다음 레벨 경험치: `60 + (현재 레벨 - 1) × 16`. 한 번에 여러 레벨을 올리면 강화 선택도 순서대로 제공합니다.
- 적은 플레이어 주변에서 생성되며, 생성 간격은 1.3초에서 점차 0.55초까지 줄어듭니다. 동시에 최대 100마리입니다.
- 과장은 25초, 부장은 60초 이후 등장합니다. 보스전에서는 일반 적 생성 간격이 1.8초로 완화됩니다.
- 경험치는 95px 이내에서 끌려오고 90초 후 사라집니다.
- 휴가신청서는 18초마다 생성됩니다. 최대 3개 보관하며, 반경 240px의 일반 적을 5초간 정지시킵니다. 연속 사용 시 종료 시간이 연장되며 보스에게는 적용되지 않습니다.
- 무기·아이템 드롭은 30초 후 사라집니다.

| 무기 | 기본 공격력 | 동작 |
| --- | ---: | --- |
| 키보드 | 12 | 회전 공격. 1/3/5레벨에서 1/2/3개. 같은 적에 대한 피해 간격 0.5초 |
| 커피 | 18 | 가까운 적에게 0.7초마다 발사 |
| USB | 10 | 사정거리 400px의 가까운 적에게 0.45초마다 발사 |
| 마우스 | 9 | 마지막 이동 방향으로 0.4초마다 발사 |
| 프린터 | 45 | 3초마다 설치. 접촉하거나 2.2초 후 반경 125px에 폭발 |

무기는 최대 3개를 장착하며 각각 6레벨까지 강화합니다. 교체하면 새 무기는 1레벨로 시작합니다.
모든 무기는 보스를 공격할 수 있습니다. 강화 수치와 게임 내 백과는 `frontend/src/config/balance.js`를 함께 사용합니다.

보스 기본 체력은 1,200, 접촉 피해는 12분입니다. 대화 기분은 -50~50 범위이며,
기분에 따라 체력이 900~1,500, 접촉 피해가 8~16분으로 변합니다.
현재 보스는 추적·접촉 공격을 합니다. 무기 진화·돌진·이메일 공격·히든 보고서는 현재 버전에 포함되지 않습니다.

목표 페이스는 약 2~3분 성장 후 남은 시간에 보스전입니다. 자동 플레이 실험은 수치 조정 참고용이며 실제 사용자의 난이도 평가를 대체하지 않습니다.
`npm run dev`를 실행한 상태에서 별도 터미널의 `frontend` 폴더에서 `npm run test:balance`를 실행하면
고정된 난수 조건으로 실제 Phaser 물리·전투 로직을 빠르게 실행해 비교할 수 있습니다.

## 구조

- `frontend/src/scenes`: 메뉴, 계정, 게임, 설명, 결과, 기록 화면
- `frontend/src/objects`: 플레이어, 적, 보스, 무기, 경험치, 아이템
- `frontend/src/config/balance.js`: 수치와 설명의 공통 정의
- `frontend/src/services/runState.js`: 일시정지 가능한 전투 시계, 성장, 공격 판정
- `backend`: Flask + SQLAlchemy 계정·기록·Gemini 대화 API
- `backend/README.md`: 온라인 모드 설정과 기존 DB 이전 절차

온라인 기능은 `VITE_GUEST_MODE=false` 빌드에서만 사용합니다. 계정·대화 API는 동일한 Flask 서버가 담당합니다.
Vite 개발 서버의 `/api` 요청은 로컬 5000번 포트로 전달합니다.

## 검증

`frontend`에서:

```text
npm test
npm run test:browser
npm run build
```

브라우저 테스트는 Windows에서 설치된 Chrome을 사용합니다. 다른 환경에서는 먼저 `npx playwright install chromium`을 실행합니다.
`PLAYWRIGHT_CHANNEL`로 브라우저 채널을 지정할 수 있습니다.

저장소 루트에서 백엔드 의존성 설치 후:

```text
python -m unittest discover -s backend/tests -v
```

단위 테스트는 시계·성장·수치·기록을, 브라우저 테스트는 강화·재시작·대화·보스 피해·아이템을 검증합니다.
백엔드 테스트는 임시 메모리 DB와 가짜 AI 응답을 사용하며 실제 계정·유료 AI API를 호출하지 않습니다.

## 배포

GitHub Pages 배포 소스는 **GitHub Actions**입니다. `main`의 프론트엔드 변경을 푸시하면
`.github/workflows/deploy-pages.yml`이 테스트·빌드·배포합니다.
프로젝트 경로는 Pages 설정에서 가져오며, 게스트판에는 API 키나 서버를 포함하지 않습니다.

PowerShell에서 하위 경로를 재현하려면:

```powershell
$env:VITE_BASE_PATH='/escapeoffice/'
npm run build
npm run preview
```

Phaser 엔진은 별도 캐시 가능한 청크로 분리합니다. 엔진 청크의 크기 경고는 남을 수 있습니다.
